# Roundnet Directory

A small, searchable directory of useful software and websites for the roundnet community.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The directory entries live in [`data/sites.ts`](data/sites.ts). Page titles and favicons are pulled from each website on the server and refreshed daily, with local fallbacks when a site is unavailable.
